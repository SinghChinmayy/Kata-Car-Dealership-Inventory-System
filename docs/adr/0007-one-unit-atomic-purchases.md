# Make purchases one-unit atomic operations

`POST /api/vehicles/{id}/purchase` represents any authenticated User Account, Standard User or Administrator, purchasing exactly one unit and accepts no request body. In one database transaction, the operation atomically decrements Stock Quantity and inserts a durable Purchase record with snapshots of its price, make, model, and category; either both changes succeed or neither does. It returns the updated Vehicle Listing; a missing listing returns 404 and an out-of-stock listing returns 409, preventing stock from becoming negative under concurrent requests or stock changes without an audit record. Later administrator edits never alter those historical snapshots.

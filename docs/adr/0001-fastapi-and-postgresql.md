# Use FastAPI and PostgreSQL

The dealership inventory system will expose its REST API through FastAPI and persist its durable application data in PostgreSQL. FastAPI was selected for concise Python API development, built-in request validation, and generated API documentation; PostgreSQL provides a production-capable relational store rather than an in-memory database.

## Considered Options

Node.js/TypeScript with Express and a document or relational database; Ruby on Rails with a relational database.
